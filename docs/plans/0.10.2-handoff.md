## What 0.10.1 ships (rc/rlx, PR #503)

Sub-PRs #502 to #542, without #507:
- **Rebrand:** the product is rlx. `rlx` and `relax` start it beside `asq` and `aisquare`. The app's top-left logo is `r\x`; everything else says rlx. The README, docs and links say rlx, and the one-line installers use the aisquare.studio/rlx short URLs.
- **Theme:** rlx is the default theme. Primary #2F74F0, accent teal #14B8A6 (the owner's pick over the old pink).
- **UI:**
  - top-right notifications (at most 3, ✕ to dismiss, drag to copy) and one copy function;
  - asq never points a person to the command line;
  - the sidebar's selected row is a coloured bar while the sidebar has the keyboard;
  - Pause beside Stop and Restart, with confirmations and a resettable "Don't ask again";
  - an agent ⋯ menu, with Rename that cascades;
  - a pick-list for bulk actions;
  - a Display tab of switches;
  - a paused agent's view says it is paused;
  - no AISquare sign-in in the sidebar (it lives in Accounts);
  - Personas live in Settings ▸ Personas, at the user level only; the project view's tabs are Manager · Board · Settings (#541);
  - Remote has a New link action, which the lockout line points at (#542);
  - Doctor shows no shell command in the app on Linux or WSL (#542);
  - Codex is no longer labelled beta.
- **README:** it opens with the `r\x` logo (docs/assets/rlx-logo.svg, outlined JetBrains Mono Medium, #2F74F0), and its CI badge reads main's push runs (#540).
- **Fleet:**
  - the board names agents as the sidebar does;
  - a manager waiting on its person is not woken by noise (standby);
  - Claude Code 2.1.326's `--add-dir` folder-trust question and 2.1.327's `/config` and `/resume` pickers are read as dialogs, so nothing is typed into them;
  - a session's end reaches the board on a slow Mac (SessionEnd hook timeout of 10 s, refreshed into existing installs, every account home included, by `aisquare upgrade`, the app's Update and the one-line installer; #521, #539).
- **Integration:**
  - usage sharing posts to `/api/v1/rlx/metrics/`;
  - AISquare sign-in uses the `rlx` OAuth client (FE page `/rlx`), falling back to `aisquare-cli` on invalid_client (400 or 401) until the server knows the rlx client; 429 and 503 never fall back and say when to try again (#531, #539);
  - Codex 0.169.1's models are priced.
- **Windows:** asq's timers no longer hold executor threads, so quitting and workers don't stall. Several Windows-only test traps are fixed.

## How the previous train ran (keep what helps)
- **Release train:** feature sub-PRs into `rc/**` get LEAN CI (Linux only). The full matrix, Windows included, runs on a push to `rc/**` or on a dispatch (`gh workflow run ci.yml --ref <branch>`). For each sub-PR:
  - dispatch the full matrix on its exact head;
  - have a tester verify that exact sha;
  - merge with `--match-head-commit <sha>`;
  - then watch rc's own push run.
- **Runners:** each push to `rc/**` also starts a duplicate full run for the rc -> main draft PR. Cancel it, and pause merging while a gate run waits for runners. The runner pool is shared org-wide.
- **Windows-only traps seen:**
  - "/" or "~" paths, or str(Path) compared with drawn text;
  - fleet calls without the in-memory tmux;
  - a stand-in binary that shutil.which cannot see on Windows (no PATHEXT);
  - widget ids reused before Textual frees them;
  - Textual timers holding executor threads.
  Reproduce on macOS by taking tmux off PATH, clearing the stand-in's exec bit, or using PureWindowsPath.
- **Before a coder says ready:** run every test file that imports a changed module, plus every test that greps a changed string. Paste each gate's last line (ruff check, ruff format --check, mypy, mypy --platform win32).
- **Nightly legs:** the `latest` Claude Code and Codex legs catch upstream drift. The 2.1.326, 2.1.327 and Codex 0.169.1 changes all arrived that way. They decide no PR, but each drift became a fix.
